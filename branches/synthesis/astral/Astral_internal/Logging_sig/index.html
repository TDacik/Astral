    Always represents session directory. It is an error to use this when Astral is not in interactive mode.

    *)
  2. | `Toplevel of filepath
    (*

    Represents the toplevel directory. In interactive mode, this is the session directory, otherwise it is the query directory.

    *)
  3. | `Query of filepath
    (*

    The directory for the current query

    *)
  4. | `CurrentSubquery of filepath
    (*

     The directory for the current sub-query

    *)
]
