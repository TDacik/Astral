The group function takes list of components for each example and creates several abstraction queries based on this decomposition. The queries are created as follows:

1. The roots of all components in all examples are collected. 2. The components are grouped by their root, if some example does not allocate a root, its pure part is used instead.

On the input, we have a list of components for each input example. We want to group together the components with the same root from all examples.

If a component for some root does not exist, the pure context is used instead. let group vars (components : SL.t list list list) = let vars = List.map SL.Term.of_var vars in let group_by main others = List.map (fun component -> let vars = SL.Term.MonoList.inter vars @@ get_vars_in_component component in SL.mk_star component :: List.map (matching_component vars) others ) main in match components with | -> | e -> List.map SL.mk_star e | main :: others -> group_by main others
